Зерно — мини-магазин кофе
Учебный проект: адаптивный интернет-магазин на чистом HTML, CSS и JavaScript, без библиотек и сборщиков.
Возможности
каталог из 10 товаров, фильтр по категориям, поиск и сортировка;
корзина: изменение количества, удаление, подсчёт суммы;
промокод COFFEE10 (скидка 10%);
бесплатная доставка от 3000 ₽, иначе 300 ₽;
оформление заказа с проверкой имени, телефона и адреса;
корзина сохраняется в браузере (localStorage);
светлая и тёмная темы, адаптивная вёрстка, управление с клавиатуры.
Запуск
Откройте index.html в браузере. Установка не нужна.
Как изменить товары
В index.html найдите массив PRODUCTS. Для каждого товара задаются name, cat, country, price, note, цвет фона bg и эмодзи e.
Что можно доработать
подключить серверную часть для приёма заказов;
добавить фотографии товаров;
добавить страницу товара.
Заказы в этой версии не отправляются на сервер: это демонстрационный проект.
